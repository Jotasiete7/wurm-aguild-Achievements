Pacote Oficial: Wurm Online Guild Tracker

Extrator leve, 100% seguro, sem necessidade de instalar o Java ou procurar pastas manualmente.

📥 Baixar Extrator da Guilda (ZIP · ~750 KB) 💻 Ver Código no GitHub
Passo 01

Baixar & Extrair

Clique no botão acima para baixar o Wurm-Guilda-Tracker.zip e extraia os dois arquivos em qualquer pasta do seu computador (como Downloads ou Área de Trabalho).

Passo 02 · Automático

Executar o Instalador

Dê dois cliques em Instalar-Guilda-Tracker.bat. Ele busca sozinho sua instalação do Wurm na Steam (C:, D:, E: etc.) e cria um atalho na sua Área de Trabalho chamado "Wurm Online (Guilda Tracker)".

Passo 03

Jogar & Comparar

Abra o jogo através do novo atalho. Quando você abrir sua janela de Achievements no jogo, o tracker captura a lista e atualiza o seu perfil no Codex automaticamente!

🛡️ Transparência & Segurança: O que cada arquivo faz?

Código 100% auditável e open source
📦 wurm_achievements.jar (800 KB) Agente Premain

Utiliza a API oficial de instrumentação do próprio Java da Oracle (javaagent). Ele atua como um ouvinte passivo: quando os pacotes da lista de conquistas chegam do servidor oficial e são desenhados na janela de interface, ele apenas anota o nome, contador e data em um arquivo de texto local (.json). Não altera mecânicas do jogo, não dá vantagens (não é bot nem hack), não toca em senhas nem lê outros arquivos do computador.

⚙️ Instalar-Guilda-Tracker.bat (Script de Configuração) Script Batch

Script transparente em lote do Windows. Ele apenas consulta o Registro do Windows e as pastas de biblioteca da Steam para encontrar o caminho onde o Wurm está instalado, copia o arquivo JAR para lá e gera um atalho na Área de Trabalho com o parâmetro de inicialização seguro. Pode ser aberto e inspecionado no Bloco de Notas por qualquer jogador.

☕ Preciso instalar o Java no meu PC? Já Incluso

Não! O próprio Wurm Online (tanto na Steam quanto no cliente oficial) já vem com o Java 21 oficial da desenvolvedora embutido na pasta do jogo (runtime\bin\java.exe). O atalho gerado utiliza diretamente o mesmo Java que o próprio jogo já usa.
